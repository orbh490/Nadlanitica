המטרה: אתר חי בכתובת חינמית (למשל `https://nadlanitica.onrender.com`), בלי כרטיס אשראי ובלי מנויים.

| חלק | שירות | עלות |
|---|---|---|
| השרת | Render, מסלול חינמי | 0 |
| מסד הנתונים | Neon (כבר פתוח ונבדק) | 0 |
| שליחת מיילים | הג'ימייל של הפרויקט | 0 |
| הצפנה (https) | אוטומטית עם הכתובת של Render | 0 |

> ⚠️ **סיסמאות ומפתחות מזינים רק במסך ההגדרות של Render** – אף פעם לא בקובץ בפרויקט, לא בגיט ולא בצ'אט.

---

## שלב 1: ג'ימייל לפרויקט + סיסמת אפליקציה

האתר שולח מיילי אימות ואיפוס סיסמה דרך תיבת ג'ימייל. ג'ימייל לא נותן לאתרים להשתמש בסיסמה הרגילה, אלא ב"סיסמת אפליקציה" נפרדת.

1. תיבת הג'ימייל של הפרויקט: `nadlanitica@gmail.com` (כבר נפתחה).
2. בחשבון החדש: **ניהול חשבון Google ← אבטחה ← אימות דו-שלבי** – להפעיל.
3. להיכנס ל-`https://myaccount.google.com/apppasswords`, לתת שם (למשל "נדלניטיקה") וללחוץ **יצירה**.
4. תתקבל סיסמה של 16 אותיות. **להעתיק אותה עכשיו** – היא מוצגת פעם אחת בלבד. זה הערך של `MAIL_PASSWORD`.

## שלב 2: מפתח ניהול

המפתח שמגן על עמוד הלידים (`/leads.html`). ליצור מחרוזת אקראית ארוכה – למשל בפקודה הזו ב-PowerShell:

```powershell
[guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')
```

לשמור את התוצאה במקום בטוח (למשל מנהל סיסמאות). זה הערך של `ADMIN_KEY`.

## שלב 3: פתיחת השירות ב-Render

1. להיכנס ל-`https://render.com` ולהירשם **עם חשבון הגיטהאב** (Sign in with GitHub). לפי מה שידוע לי, המסלול החינמי לא דורש כרטיס אשראי – אם בכל זאת מבקשים, לעצור ולבדוק.
2. **New ← Web Service**, ולחבר את המאגר `orbh490/Nadlanitica` (לאשר ל-Render גישה למאגר הזה בלבד).
3. למלא:
   - **Name:** `nadlanitica` – זה קובע את הכתובת. אם השם תפוס, Render יוסיף לו תוספת, וזו תהיה הכתובת.
   - **Branch:** הענף העדכני ביותר – כרגע `feat/free-deploy` (אחרי שנמזג הכל ל-`main`, להחליף ל-`main`).
   - **Region:** Frankfurt (הכי קרוב לישראל, ובאותו אזור כמו מסד הנתונים ב-Neon).
   - **Language / Runtime:** Docker.
   - **Instance Type:** Free.
4. תחת **Environment Variables** להוסיף את כל המשתנים מהטבלה בשלב 4.
5. **Create Web Service**. הבנייה הראשונה לוקחת כ-5–10 דקות.

## שלב 4: משתני הסביבה

| משתנה | ערך |
|---|---|
| `SPRING_PROFILES_ACTIVE` | `production` |
| `PG_HOST` | הכתובת מ-Neon (מתחילה ב-`ep-` ומסתיימת ב-`neon.tech`) |
| `PG_DATABASE` | `nadlanitica` |
| `PG_USER` | `nadlanitica_owner` |
| `PG_PASSWORD` | הסיסמה מ-Neon |
| `MAIL_USERNAME` | `nadlanitica@gmail.com` |
| `MAIL_PASSWORD` | סיסמת האפליקציה משלב 1 (16 אותיות, בלי רווחים) |
| `MAIL_FROM` | `nadlanitica@gmail.com` (אפשר לדלג – זו ברירת המחדל) |
| `CONTACT_EMAIL` | `nadlanitica@gmail.com` (אפשר לדלג – זו ברירת המחדל) |
| `ADMIN_KEY` | המפתח משלב 2 |
| `BASE_URL` | הכתובת ש-Render נתן לשירות, למשל `https://nadlanitica.onrender.com` (בלי `/` בסוף) |

> את `BASE_URL` יודעים רק אחרי שהשירות נוצר. אפשר להזין ערך זמני, ואחרי היצירה לתקן לכתובת האמיתית ולשמור – Render מפעיל מחדש לבד. בלי הכתובת הנכונה, הקישורים במיילי האימות לא יעבדו.

## שלב 5: בדיקה אחרי העלייה

1. במסך **Logs** של השירות לחפש `Started NadlaniticaApplication`.
2. לפתוח את הכתובת של האתר ולעבור על העמודים.
3. **מכרזי קרקע ומחיר למשתכן:** לבדוק שהרשימות נטענות. אם לא – כנראה שהאתרים הממשלתיים חוסמים שרתים מחוץ לישראל, וזה בדיוק מה שרצינו לגלות בשלב הזה.
4. **הרשמה:** להירשם עם כתובת מייל אמיתית ולבדוק שמייל האימות מגיע (גם בספאם) ושהקישור בו עובד.
5. **עמוד הלידים:** `/leads.html` עם מפתח הניהול.

## מגבלות המסלול החינמי

- **השרת נרדם** אחרי 15 דקות בלי ביקורים. המבקר הבא יחכה כדקה–שתיים עד שהוא מתעורר.
- **זיכרון 512MB:** האפליקציה מכוונת לזה (נמדד: שיא של כ-450MB בעומס מלא). אם הזיכרון ייגמר, השרת נסגר ו-Render מפעיל אותו מחדש.
- **משימות לילה** (ניקוי, עדכון ריבית בנק ישראל) רצות רק כשהשרת ער – לאתר ניסיוני זה בסדר.

## עדכונים

כל העלאה (push) לענף שנבחר ב-Render מעלה גרסה חדשה לאוויר אוטומטית.

## מעבר לדומיין בעתיד

כשיהיה דומיין: לחבר אותו ב-Render (Settings ← Custom Domains), לעדכן את `BASE_URL`, ולעבור לשליחה דרך Brevo לפי שלב ג בתוכנית העבודה. שום דבר בקוד לא צריך להשתנות.
